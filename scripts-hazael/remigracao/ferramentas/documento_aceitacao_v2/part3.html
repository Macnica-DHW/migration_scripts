5. Decisions and open points

The points below were questions for Anion in version 1.0 of this document. Anion is not expected to answer them, so each one is now settled: Decided marks the rule we have agreed internally and already applied to pages; Open marks what is still undecided. A Decided point is a criterion pages are accepted against, the same way as the guidelines in Section 4; an Open point still needs a decision before the pages it affects can be finished.

5.1 Layout

A1 Side padding (G7) Decided

Review of 27 Sep: Need to give Padding Left/Right for all Altera, Anlog, microchip, on-semiconductor, sitime pages. Review of 28 Sep: L/R Padding - should be large. The pictures are in Figure .

Padding - Left/Right: Large (50px each side) on every top-level section of every page. It gives every page the same margins, and it keeps the full-width layout.

A2 Heading levels and sizes (G5) Decided

Review of 28 Sep: only main title should be h1/h2, remaining titles should not be h1.

A2.1 Levels. The page title is the only H1; section titles are H2; titles inside a section are H3; a title inside that subsection (for example, a title that follows an H3 and introduces part of its content) is H4. No level is skipped going down.

A2.2 Sizes. The theme sizes apply on every heading: H1 25px, H2 29px, H3 22px, H4 18px. A heading level always looks the same, including headings typed inside Text or Text with Image.

A3 A section title next to an image (G5, G10) Decided

Many GWI sections open with a title, an image and a paragraph. Review comments: Titles are kept as para (IBASE IB836, 28 Sep); there’s gap between title and description. Press Shift+Enter after Title to avoid space. (MB991, 27 Sep).

The section title is the first line of the Text with Image text, formatted as a heading at the level A2 gives it (H2 for a section title, H3 or H4 when the title sits deeper), so that it sits beside the image without an extra gap. Where a Title component and a Text with Image already sit side by side as separate components, the Title's text moves into the Text with Image as its first line, and the separate Title component is removed. This also applies where a title needs to move into a Text with Image that currently holds an unrelated image: the image moves into the same Text with Image as the title's text, and the title that introduced the image (if any) is kept as a separate heading above it.

A4 Table format (G13) Decided

Review of 28 Sep: Tables are not formatted, table headers issue, table formatting. The pictures are in Figure .

On a two-column table, the first column (the row's label) is set to a fixed width, left-aligned: 20% by default, or 30% on pages where the label text needs more room. The second column takes the rest of the width, with no width style of its own. A row that spans both columns (a group heading inside the table, such as Communication or I/O Interface) is a centred header cell with a light grey background (rgb(247,247,247), the same grey as the page's background bands); the normal label cells of the first column keep no background colour. Where a page's reviewer asks for every cell centred instead of left-aligned, that page's tables are centred throughout, overriding the default left alignment of the first column.

A5 Images without text beside them (G11) Decided

Review of 28 Sep: make image to full width to avoid space left and right (Japan Innovation Showcase). An image enlarged far beyond its file looks blurred, so the choice depends on the file's width. The pictures are in Figure .

A5.1 Placement. As in G11: a diagram, chart or screenshot is shown at its file width (content width if wider); a file at least 900px wide fills the content width (enlarged at most 1.5 times); an image next to a paragraph on GWI goes beside it in a Text with Image; any other image is shown at its file width, aligned left with the text. No blurred images and no image left alone in the middle of the page.

A5.2 Full width. Means the content width (1,300px with the side padding of A1): the image has the same left and right edges as the text.

A6 Grey bands (G9) Decided

As written in G9: bands group the main sections of a page; no band on pages without images, videos or tables, or on news, press and event items. It follows both comments of 27 Sep and gives every page type one rule.

5.3 Content

M1 Content from GWI (G1) Decided

Confirmed: text, images, links, tables, videos, downloads, page titles and descriptions are migrated as on GWI, with only the differences listed in G1. Content changes are requested separately and are not part of page acceptance.

M2 Which pages end with contact buttons, and how they are built (G14) Decided

Review of 23 Sep: CTAs are missing (IBASE); review of 27 Sep: CTAs at bottom not required (news items). On GWI, news, press and event pages end without a Contact / Request a Quote pair; most newsletter issues end with a single Request a Quote button, and the others end as their GWI pages do.

Every page ends as its GWI page does: the contact pair only where GWI shows it, a single Request a Quote only where GWI shows one, and no end buttons where GWI has none (news, press and event items included). It matches GWI and the review of 27 Sep.

Any title placed above a pair of end-of-page buttons (for example a Stay up to date… / For more information: pair) is removed; the buttons stand alone. The pair sits in a four-item Flex Container: an empty item first, the two button items in the middle, an empty item last, which centres the pair more than two items alone would. Fit to Text is applied to every such button so a long label does not wrap or force the button wider than it needs to be.

M3 Alternative text where GWI has none (G3) Decided

A short alternative text taken from words already on the page: the heading of the block the image belongs to, else the nearest title above it, else the page title. Every image then has a text alternative, using only words that are already on the page.

6. How review works

J1 Format of review comments Decided

Each comment names the page, the block (title or first words), the guideline it does not meet (G1 to G19), and the expected result. A comment that no guideline covers is marked new guideline; once agreed, it is added to this document and applies to the pages not yet accepted (J2).

J2 Accepted pages and later changes Decided

A page that meets every guideline is ready for acceptance. Once it is accepted, a guideline added or changed later applies only to pages not yet accepted; accepted pages are changed only on request.

J3 Who accepts each page Decided

Anion reviews each page against this document; Macnica Americas gives the final acceptance. Anion checks each page against the agreed guidelines, and the site owner makes the final decision.

J4 The reference for a page's layout Decided

Review of 23 Sep: Compare both MAI and MAE (the Americas and the Europe pages).

The reference is the page's GWI arrangement, adapted to global2 as described in Section 2 and the guidelines of this document. A Europe page is an example only where a guideline or a decision in Section 5 names it. Each Americas page has one reference, its own GWI page, so reviewers judge it the same way.

J5 Pages whose last review raised only headings Decided

On 28 Sep the review of these pages raised only the heading rule: the three Hitek pages, IEI Embedded Systems, IBASE MB995, SiTime Clock Buffers, the Contact download page, the error page, and Japan Innovation Showcase (headings and the full-width image).

Once they meet G5 (and G11 for Japan Innovation Showcase), they are ready for acceptance without a new full review.
